#  Smart Solar Inverter 

##  Overview

This project is a **Smart Solar Inverter Monitoring System** that tracks solar power generation, battery status, and load usage in real-time.

It helps improve energy efficiency and provides alerts for critical conditions.

##  Features

*  Battery level monitoring
*  Solar power tracking
*  Load usage monitoring
*  Low battery alerts
*  Simple dashboard display

##  Technologies Used

* Python
* HTML & CSS
* JSON (for data storage)
* (Future) Arduino / ESP32
